# Versions disponibles

Cette page recense les versions publiées et les composants inclus dans la
release stable actuelle. Les tags sont la référence immuable du code publié :
[tous les tags PerfComparator](https://github.com/frchalaoux/perfcomparator/tags).

## Version stable actuelle

| Composant | Paquet Python | Version source |
| --- | --- | --- |
| PerfComparator Engine (PCE) | `perfcomparator` | `0.5.2` |
| PerfComparator Web (PCWEB) | `perfcomparatorweb` | `0.1.1` |

## Consulter les anciennes versions

Les releases plus anciennes restent accessibles depuis la
[liste GitHub des releases](https://github.com/frchalaoux/perfcomparator/releases)
et leurs tags. Les instructions historiques d’installation et d’utilisation
de la `v0.5.0` sont conservées dans
[`docs/archive/v0.5.0/`](archive/v0.5.0/index.md), avec une copie des documents
qui accompagnaient son tag.
