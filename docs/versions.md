# Versions disponibles

Cette page sépare les releases que l’on peut télécharger du code actuel qui
attend encore sa release. Les tags sont la référence immuable du code publié :
[tous les tags PerfComparator](https://github.com/frchalaoux/perfcomparator/tags).

## Code actuel

La branche `main` contient actuellement :

| Composant | Paquet Python | Version source |
| --- | --- | --- |
| PerfComparator Engine (PCE) | `perfcomparator` | `0.5.1` |
| PerfComparator Web (PCWEB) | `perfcomparatorweb` | `0.1.1.dev0` |

Cette architecture locale à deux services n’a pas encore de release avec ses
installateurs. Les versions ci-dessus décrivent le code fusionné, pas un
téléchargement public.

## Releases installables existantes

| Version | État | Documentation |
| --- | --- | --- |
| [`v0.5.0`](https://github.com/frchalaoux/perfcomparator/releases/tag/v0.5.0) | Stable publiée ; ancienne application de bureau | [Documentation archivée de la 0.5.0](archive/v0.5.0/index.md) |
| [`v0.5.0.dev0`](https://github.com/frchalaoux/perfcomparator/releases/tag/v0.5.0.dev0) | Préversion publiée de l’ancienne application | [Documentation exacte du tag](https://github.com/frchalaoux/perfcomparator/tree/v0.5.0.dev0) |

La [page de téléchargement](https://frchalaoux.github.io/perfcomparator/)
propose les fichiers joints aux releases. Avant de télécharger, vérifiez le
nom et la version de la release : la `v0.5.0` n’inclut pas les fonctionnalités
actuelles de PCE et PCWEB.

## Consulter les anciennes versions

Les releases plus anciennes restent accessibles depuis la
[liste GitHub des releases](https://github.com/frchalaoux/perfcomparator/releases)
et leurs tags. Les instructions historiques d’installation et d’utilisation
de la `v0.5.0` sont conservées dans
[`docs/archive/v0.5.0/`](archive/v0.5.0/index.md), avec une copie des documents
qui accompagnaient son tag.
