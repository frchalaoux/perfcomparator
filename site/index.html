Télécharger PerfComparator

Choisissez l’installateur de votre système. Il préparera uv, Python avec Tk et PerfComparator, puis créera un lanceur pour ouvrir l’application.

Détection du système…

macOS — Intel ou Apple silicon

L’installateur crée l’application PerfComparator dans votre dossier Applications.

Télécharger pour macOS

Windows

L’installateur crée une icône PerfComparator sur le Bureau.

Télécharger pour Windows

Linux — x86-64

Pour Ubuntu et Debian, installez le paquet (confirmation système requise), puis lancez l’installateur PerfComparator depuis le menu des applications. uv, Python/Tk et l’application restent installés dans votre compte. Pour les autres distributions, utilisez l’archive autonome ; GNOME peut demander d’autoriser une fois son lanceur téléchargé.

Télécharger le paquet Ubuntu/Debian (.deb)

Autres distributions Linux :

Télécharger l’archive Linux (.tar.gz)

La détection sert à mettre en évidence le bon choix ; vous pouvez toujours sélectionner un autre système. Les téléchargements ne démarrent qu’après votre clic.
